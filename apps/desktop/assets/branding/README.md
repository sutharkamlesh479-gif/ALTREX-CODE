# ALTREX branding assets

These files are deterministic derivatives of the two official raster images supplied by the product owner on 2026-08-10. They are not generated or redesigned.

- `altrex-app-icon.png`: Logo A mark, cropped from the official product logo for interface and high-DPI application identity.
- `altrex-app-icon.ico`: Logo A Windows icon containing 16, 24, 32, 48, 64, 128, and 256px PNG frames.
- `altrex-wordmark.png`: untouched official Logo A source with the ALTREX CODE wordmark.
- `altrex-code-symbol.png`: Logo B coding-intelligence symbol cropped from the official source.

Rebuild with:

```powershell
node scripts/build-brand-assets.mjs <official-logo-a.png> <official-logo-b.png>
```

Do not substitute, recolor, trace, or swap the roles of Logo A and Logo B.
